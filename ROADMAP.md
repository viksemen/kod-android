# Направления развития КОД / Roadmap

![Идеи развития](assets/roadmap.png)

Инфографика отражает идеи развития, а не подтверждённый список функций текущей версии или обязательства по срокам. Некоторые возможности могут уже присутствовать частично. Статус каждой требует отдельной проверки.

- Вход по Passkey.
- ID и QR для обмена контактами без раскрытия номера телефона.
- Зашифрованные резервные копии.
- Проверка собеседника и сверка ключей.
- Исследование MLS для защиты групп.
- Контекст неизвестного звонка.

English: these are development directions, not a release commitment or a verified list of current features.
