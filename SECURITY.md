# Security / Безопасность

Не публикуйте действующие уязвимости, ключи, токены или персональные данные в открытых Issues. Если в репозитории доступна функция Security → Report a vulnerability, используйте её для приватного сообщения. Если она недоступна, запросите приватный канал у владельца репозитория без технических подробностей. Укажите версию приложения, описание, шаги воспроизведения и возможные последствия. Тестируйте только собственные устройства и системы с разрешения владельца. Не обещается конкретный срок ответа или вознаграждение.

Do not post exploitable vulnerabilities, keys, tokens or personal data in public issues. Use Security → Report a vulnerability if enabled; otherwise request a private channel from the repository owner without technical details. Include version, description, reproduction steps and impact. Test only authorized systems. No response deadline or bounty is promised.
